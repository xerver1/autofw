## 2. 探针清单

### A1 validate 探针
构造最小 flow JSON（含 sub_call / wait_image / pinch 节点各一），POST `http://127.0.0.1:8765/api/flows/validate`：

- 定预案：①未知 op 挂已知 type 下能否通过；②C9 运行图校验是否需要改运行图校验逻辑。

### A2 run 接口契约抄录
读 `gui/server.py` 中 `/api/flows/run` handler：
- 抄录请求体 schema（字段名、类型、必填）；
- 验证"运行图不落盘"是否可行（请求体直传 vs 必须先保存）。

### A3 引擎语义抄录
读 `core/flow_engine.py`：
- condition cfg schema（字段名与取值）；
- loop_while 真值语义（真=继续还是退出）；
- 有无 negate/取反字段；
- 结论直接决定 buildRunFlow 真值表（源文档 §4.3）是否需修正。

### A4 编辑器锚点与 undo 栈侦察
在 flow_editor.html 中：
- grep 定位保存函数（`fetch('/api/flows/save'` 或等价）行号；
- 检查 markDirty 是否含 previewing 守卫（`if (S.previewing) return` 或等价）；
- undo 栈实现方式（数组快照 or 命令模式），覆盖 S.graph 草稿后是否需要重置。
- 本项对应勘误 #10/#22。

### A5 T5 数据恢复评估
按 D-R1d：确认 MEMORY.md 暂存版不可达后，评估附录 A 重构版重建成本：

- 写入 F-A5：骨架草案 + 预期结构计数推演过程。

### A6 emitIf 计数矛盾实测
