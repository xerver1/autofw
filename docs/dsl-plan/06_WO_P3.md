## 2. 反解规则（内联全文）

1. 识别顺序：先按子图键后缀分组（`:true/:false` → if；`<loopId>` body + 头节点 kind → for/while/loop；
   `:caseN/:default` → switch），再在组内按 entry→end 走链；
2. break 边（label=break）→ 生成 `break` 行，位置 = 目标 end 所属 body 内最后语句之后；
3. else-if 链：false 键内若为嵌套 if_else，输出 `else if` 折叠形式（不是平铺嵌套）；
4. 空 false 分支（start→end 直连）→ 只输出 `if ... end` 不带 else；
5. 缺 default 的 switch → 不输出 default 分支；
6. dslLine 字段存在时用于稳定性校验（见 T4），缺失时全量重建。
