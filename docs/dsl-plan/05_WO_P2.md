## 2. 子图键规则（内联全文）

- main → `S.graph` 本体；`sub:<名>`；循环 body → `<loopId>`；
- if/else → `<id>:true` 与 `<id>:false` **两键都必须非空**（缺 else 时 false 键含 start→end 直连）；
- switch → `<id>:case<N>` 每分支一键 + `<id>:default`（缺 default 时 default 键为空图并记 warning）。

## 3. break 边（D-R1c 定稿）

break 出边指向**所在循环 body 子图的 end 节点**，edge label=`break`；不跨子图。
AST 的 break 节点已带所属循环 id（P1b 产出），直接消费。

## 4. graphHash（勘误 #1/#2）

- canonical(x)：键递归排序后 JSON.stringify；
- hash = FNV-1a 32bit(canonical(graph))，十六进制 8 位；
- 产出图对象携带 `graphHash` 字段——**禁止**使用旧字段名 `hash`。
